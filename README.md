# Ruang Belajar FK UI

Web belajar pribadi: perencana harian, materi, kuis, bank kesalahan, rapor, dan target TOEFL / TKA / UTBK.

- `index.html` dan `app.js`: tampilan dan program.
- `data/topics.js`: daftar materi dan tahapnya.
- `data/lessons.js`: ringkasan materi per bab.
- `data/questions.js`: bank soal.
- `data/kisikisi.js`: peta kisi-kisi TKA, UTBK, TOEFL, kelas 11, plus daftar yang belum dimasukkan.
- `assets/logo-ui.png`: logo (opsional).

Materi dan soal baru cukup ditambahkan di folder `data`.
